# CV bullets — GatePulse

## Project title
**GatePulse** — Multi-campus school operations analytics (ETL, data quality, FastAPI UI, AI deadline-slip risk)

## Bullets
- Built an end-to-end analytics demo for **exam / term / inspection readiness** across four fictional school campuses using fully synthetic data.
- Automated a Python **ETL + data-quality pipeline** (invalid dates, missing progress, bad categories) with SQLite publish and issue logging.
- Developed a **custom FastAPI + HTML/CSS/JS** control surface (Deck, Engine, Data, Model, Campuses) where backend pipeline stages can be re-run from the browser.
- Trained an offline **RandomForest model** to prioritize programmes most likely to miss exam or term-start deadlines; exposed feature importance and what-if scoring.
- Produced **Excel + SLT brief** exports; documented product decisions and idea sources in a decision log.

## Cover letter one-liner
I built GatePulse, a working multi-campus operations tool that combines checklist data quality, interactive analytics, and AI-supported deadline-risk prioritization for exams and term-start gates.
