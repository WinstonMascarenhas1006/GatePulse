# CV bullets — GatePulse

## Project title
**GatePulse** — Multi-plant NPI launch readiness analytics (ETL, data quality, dashboards, AI SOP-slip risk)

## Bullets
- Built an end-to-end analytics demo for **new product introduction / SOP launch gates** across four plants (DE/CZ/MX/MY) using fully synthetic data.
- Automated a Python **ETL + data-quality pipeline** (invalid dates, missing progress, bad categories) with SQLite publish and issue logging.
- Delivered a **custom FastAPI + HTML/CSS/JS control surface** (not Streamlit) with Deck, Engine, Data, Model, Launches, and Exports views wired to the Python backend.
- Trained an offline **RandomForest model** to prioritize launches by SOP-slip risk and generated manager-facing insights.
- Produced **Excel + executive brief** exports for gate reviews; documented every product decision and idea source in a decision log.

## Cover letter one-liner
Alongside my studies I built GatePulse, a working launch-readiness analytics tool that combines checklist data quality, operational dashboards, and AI-supported prioritization for multi-plant NPI programs.
