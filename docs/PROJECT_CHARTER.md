# GatePulse — Project Charter

## Problem
NPI launches fail quietly when gate status, checklist quality, and plant workload are opaque. Teams need a lightweight intelligence layer before buying enterprise PLM analytics.

## Goal
Ship a reproducible demonstrator: synthetic launches → clean data → quality scores → AI slip risk → dashboard → steering exports.

## Non-goals
- Real company data
- Cloning any employer’s internal certification process
- Production auth / SaaS multi-tenancy

## Success criteria
1. One-command pipeline refresh
2. Dashboard covers overview, launches, quality, AI, exports
3. Decision log includes sources for ideas
4. Domain deliberately adjacent to — not identical to — automotive certification trainee postings
