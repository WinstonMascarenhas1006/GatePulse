# GatePulse — Project Charter

## Problem
Exam days and term starts fail quietly when campus checklists, staffing, and hall bookings are opaque. SLT needs one pulse before the next governor meeting.

## Goal
Ship a reproducible demonstrator: synthetic campus programmes → clean data → quality scores → AI deadline-slip risk → dashboard → SLT exports.

## Non-goals
- Real pupil records
- Cloning any employer’s internal process
- Production auth / SaaS multi-tenancy

## Success criteria
1. One-command pipeline refresh
2. UI covers Deck, Engine, Data, Model, Campuses, Exports
3. Decision log includes sources for ideas
4. Domain is school operations (four campuses), not a JD photocopy
